# Profil server (recommandé)

Inclut Alpine 3.22, OpenRC, rootfs microSD, noyau #35, rootfix, USB ECM
(10.71.0.2/30), RNDIS (172.16.42.1/24), SSH par clé, DNS, chrony, a71-clock,
journaux 5/30/60/90 s, ttyMSM0 et récupération documentée.

Exclut Mesa, SQE/GMU spécialisés, ZAP, Wi-Fi, Bluetooth, audio, outils de
développement et benchmark.

Aucune clé SSH privée ni host key n'est incluse dans les images.
